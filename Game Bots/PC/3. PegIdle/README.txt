# PegIdle Auto Shooter

## Overview
Tracks the basket and makes a rudamentory guess on where to aim the cursor and shoots the ball that should fall into the basket, assuming nothing is in the way of the ball and basket.

## Features
- Hotkey to start and quit the bot.
- TEmplate matching for the basket.
- Keeps short record of basket to calculate pathing.
- calculates pathing of the basket to lead a shot.
- Automates the process of the user aiming and shooting the balls.

## Technologies
- pyautogui
- threading
- keyboard
- time
- sys
- cv2
- numpy
- os
- deque

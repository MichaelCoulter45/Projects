# Gamblers Table Auto Flipper

## Overview
Measures the game window and game table region to move the mouse randomly inside the table region to flip as many coins as possible.

## Features
- Hotkey to start and quit the bot.
- Mouse move automation
- Mouse clicking automation

## Technologies
- win32api
- win32gui
- keyboard
- pyautogui
- time
- sys
- random

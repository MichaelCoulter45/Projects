# TreasureChestClicker Auto Upgrades

## Overview
Clicks on specific points relative to the game window to purchace upgrades in the game, automating the process.

## Features
- Hotkey to start and quit the bot.
- Hotkey to print the mouse's postion for debugging and adding new click targets.
- Automates the process of the user clicking upgrades and items.

## Technologies
- sys
- time
- threading
- keyboard
- win32api
- win32con
- pyautogui

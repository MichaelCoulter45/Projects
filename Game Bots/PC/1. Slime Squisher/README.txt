# Slime Squisher clicker bot

## Overview
Matches templates to slimes and clicks the center of the match to squish them. The bot will continue to squish slimes until the user stops it.

## Features
- Hotkey to start and quit the bot.
- Uses pre-made templates to match slimes.
- automatically clicks the center of the matched slime to squish it.

## Technologies
- pyautogui
- cv2
- dxcam
- os
- sys
- time
- keyboard
- random
- threading
- Pymem

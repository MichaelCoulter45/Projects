# Kiwi Clicker Auto Upgrader

## Overview
Measures the game window and clicks at certain pre determined points relative to the game window to automate buying upgrades in the game.

## Features
- Hotkey to start and quit the bot.
- Mouse move automation
- Mouse clicking automation

## Technologies
- win32api
- win32gui
- win32con
- keyboard
- time
- sys
- pyautogui
- random
